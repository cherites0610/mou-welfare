# 哞福利 mou-welfare

一站式政府福利查詢平台（重寫中）。

## 舊版（v1）

舊版程式碼已封存為 tag，不再於 `main` 上開發：

| Tag | 內容 | 原分支 |
|---|---|---|
| `v1-api` | NestJS 後端、Python 爬蟲 | `api` |
| `v1-web` | Vue 3 前端 | `web` |

```bash
git checkout v1-api   # 查看舊版後端
git checkout v1-web   # 查看舊版前端
```

v1 的 API 端點、前端頁面與樣式指南整理在 [`docs/v1/`](docs/v1/)（用瀏覽器開 `index.html`）。
