路由層面的問題

問題影響
路由名稱 Question 重複（Layout 子路由與最外層各一個）Vue Router 以後加者為準，常見問題頁沒有 Layout 外框（頁面裡又自己塞了一個 AppHeader 補救）
/favorites 沒有 requiresAuth未登入可進入，API 回 401
<keep-alive :include="['WelfareList','Chat']">比對的是元件名稱而非路由名稱；<script setup> 元件沒有 defineOptions({ name })，所以快取完全沒生效，返回列表會重新載入、捲動位置遺失
/favorites、/private、/terms、/question 在 Layout 外手機底部導航與桌機頂部 Header 在這些頁面消失，各頁自己做返回列
App.vue 印出 LIFF ID Token 到 console上線前應移除
依 origin/web 分支程式碼靜態整理，未實際執行前端。
